# Obsidian 笔记编写与排版规范 (NOTE_STANDARD)

本规范适用于《人工智能：现代方法（第4版）》Obsidian 知识库中的全部章节笔记、专题笔记、索引文件与审核报告。

## 1. 文件编码与命名规范
- **编码格式**：统一使用 `UTF-8` Markdown（`.md`），换行符统一使用 LF。
- **章节主笔记命名**（位于 `02_教材逐章笔记/<对应部分>/`）：
  - 格式：`ChXX_<章节中文名>.md`（两位数字补零），例如 `Ch01_绪论.md`、`Ch13_概率推理.md`。
  - 附录命名：`AppendixA_数学背景知识.md`、`AppendixB_关于语言与算法的说明.md`。
- **专题笔记命名**（位于 `03_专题知识网络/<对应专题>/`）：
  - 格式：`T_<专题概念名>.md`，确保全库文件名**全局唯一**，从而支持 Obsidian 最短路径双向链接 `[[文件名]]` 无歧义跳转。
- **图片资源命名与路径**（位于 `99_附件与脚本/assets/chXX/`）：
  - 格式：`chXX_figYY_<简短英文或拼音描述>.png`（如 `ch03_fig04_search_tree.png`）。
  - 必须使用**相对路径**引用，例如在 `02_教材逐章笔记/02_第二部分_问题求解/Ch03_通过搜索进行问题求解.md` 中写作：
    `![图3-4 搜索树示例](../../99_附件与脚本/assets/ch03/ch03_fig04_search_tree.png)`

## 2. YAML Frontmatter 规范
每篇章节笔记顶部必须包含如下 YAML 元数据：

```yaml
---
title: "第X章 章节标题"
book: "人工智能：现代方法（第4版）"
part: "第X部分 名称"
chapter: X
source_file: "XX_第X章 标题.pdf"
orig_pdf_pages: "起始-结束"
printed_pages: "起始-结束"
status: "drafted" # 可选值: pending | drafted | audited
tags:
  - AIMA4e
  - PartX
  - ChXX
prerequisites:
  - "[[前置章节或专题]]"
next_chapters:
  - "[[后续章节或专题]]"
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

## 3. 内容来源区分与页码标注规范
严格区分三类知识来源，不得混为一谈：
1. **教材原文内容**：使用 `> [!note] 教材核心定义` 或正文直接陈述，并在关键结论/公式/图表后标注页码，格式为 `(第X章 节号, 印刷 p.Y / 拆分 p.Z)`。
2. **模型推导补充**：教材仅给出结论或跳步的推导，使用 `> [!abstract]- 详细数学推导（模型补充）`（可折叠 Callout）展开每一步演算。
3. **教材之外的拓展知识**：前沿进展、工程实践或对比视角，使用 `> [!tip] 拓展视野（教材之外）` 并注明参考出处或学界共识。

## 4. 数学公式与代码排版规范
- **Obsidian 兼容 LaTeX**：
  - 行内公式用 `$...$`（注意 `$` 内侧不要留多余空格，如 `$P(A \mid B)$`）。
  - 独立公式块用 `$$ ... $$` 单独成段，前后各空一行。
  - 多行推导使用 `\begin{aligned} ... \end{aligned}`。
  - **PDF 公式核对铁律**：由于原书 PDF 部分分式与独立公式以图片/矢量图嵌入，禁止只根据纯文本拷贝猜测公式，必须对照 PDF 页面图像逐符号核对！
- **代码块规范**：
  - 伪代码标注 `text` 或 `pseudocode`（并尽量贴近原书附录 B 风格），Python 实现标注 `python`。
  - 所有 Python 代码必须是**独立可运行的完整代码**（含必要 `import`、测试示例和中文注释），严禁写残缺伪代码冒充 Python。

## 5. 图表与 Obsidian Callout 规范
- **优先 Mermaid**：概念框架、搜索过程、算法决策流、概率依赖关系优先使用 Mermaid（`flowchart TD`、`sequenceDiagram`、`stateDiagram-v2` 等）；若节点标签含括号或特殊字符，必须用双引号包裹，例如 `A["A* 算法 (f = g + h)"]`。
- **Python / SVG 绘图**：函数图像（如 sigmoid vs probit）、几何空间、收敛曲线可用 Python `matplotlib` 绘制后存入 `99_附件与脚本/assets/chXX/`。
- **常用 Callout 类型**：
  - `[!info]`：本章导读、来源信息与前置依赖
  - `[!note]`：核心定义、定理与公理
  - `[!abstract]-`：可折叠的完整数学推导
  - `[!example]`：教材经典例题与练习解析
  - `[!warning]`：常见误区、边界条件、易混淆概念对比
  - `[!tip]`：直观比喻、工程实现技巧与教材外拓展

## 6. 知识点去重与双向链接规范
- 凡涉及跨章节通用概念（如“条件独立性”“贝叶斯法则”“启发式可采纳性”“动态规划/贝尔曼方程”），若已在 `03_专题知识网络/` 建立独立专题笔记，章节中仅做情境化说明并通过 `[[T_专题名]]` 链接，避免在多处重复抄写大段基础定义。
- 笔记末尾必须附带**本章索引同步清单**（新增中英文术语、核心公式、算法复杂度），便于更新 `01_全局索引与知识地图/` 中的三大索引。
