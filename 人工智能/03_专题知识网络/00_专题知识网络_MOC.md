# 专题知识网络总览

> [!abstract] 设计原则
> 教材按“章节”线性讲授，而真实掌握 AI 需要**按“主题”纵横串联**。`03_专题知识网络/` 下的 8 个专题域用于沉淀跨章节的通用核心概念与数学工具；章节笔记中不再大段重复这些通用基础，而是通过双向链接 `[[T_专题名]]` 统一指向这里。

## 八大专题域与章节映射

| 专题目录 | 涵盖核心主题（随逐章推进逐步建档） | 主要关联教材章节 |
| :--- | :--- | :--- |
| `01_数学基础/` | 渐近复杂度、向量矩阵与微积分、信息熵与KL散度、概率公理、凸优化与拉格朗日乘子 | [[AppendixA_数学背景知识]]、Ch12、Ch19、Ch21 |
| `02_核心搜索与优化算法/` | 状态空间建模、盲目搜索对比、启发式可采纳/一致性、局部搜索与退火、博弈树与MCTS、CSP约束传播 | Ch03–Ch06、Ch11 |
| `03_知识表示与逻辑推理/` | 语义蕴涵与句法推导、SAT/DPLL、合一与归结、情景/事件演算、本体工程、PDDL规划 | Ch07–Ch11 |
| `04_概率图模型与不确定推理/` | d-分离、贝叶斯网络推断（精确vs采样）、HMM/卡尔曼滤波/DBN、概率编程、期望效用与VPI、MDP/POMDP | Ch12–Ch18 |
| `05_机器学习与深度学习/` | 偏差-方差权衡、交叉验证与正则化、MLE/MAP/EM、核方法与SVM、集成学习、CNN/RNN/Transformer、生成模型 | Ch19–Ch21 |
| `06_强化学习与多智能体/` | 探索与利用、TD/Q-learning/SARSA、策略梯度与Actor-Critic、深度RL、博弈均衡与机制设计 | Ch05、Ch17–Ch18、Ch22 |
