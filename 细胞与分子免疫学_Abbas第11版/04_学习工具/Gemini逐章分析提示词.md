# Gemini 逐章分析提示词

每次上传一章 PDF，在新对话中使用以下提示词；章号和章名按当前文件填写。

```text
请根据我上传的《Cellular and Molecular Immunology》第11版的本章PDF，生成一份完整、系统、适合本科高年级生命科学学生学习的中文 Obsidian Markdown 笔记。每章只输出一个 Markdown 文档，保留关键专业术语的英文。目标是帮助我理解并复习教材，而非逐段翻译。

先确认章号、英文标题、上传文件的总页数，并列出你实际能够阅读的范围。若文件不完整、图片不可读或超出处理能力，请明确指出，不要假装已读完。分析前先梳理原书所有小节，并以此作为覆盖清单。

正文至少包含：
1. 本章核心问题、学习目标，以及与前后章节的关系。
2. 按原书小节展开的知识梳理，保留重要层级；解释概念、细胞类型、分子、受体、配体和功能。
3. 机制的因果链：起始刺激→识别细胞与受体→信号通路→转录或细胞状态变化→效应功能→终止及负反馈。教材未提供的环节直接注明，不得补造。
4. 易混概念的比较表；适用时整理细胞、细胞因子、受体、信号分子和转录因子，并说明人体与小鼠结论是否不同。
5. 逐项解释本章关键图表：图表编号、所回答的问题、阅读顺序、机制与结论。标出原书印刷页码和本章PDF页序；只标可确认的编号与页码，无法确认时写“待核对”。图片无法读取时直接说明。
6. 实验依据、研究方法和临床关联：仅在本章涉及的范围内展开，说明从证据到结论的逻辑与限制。
7. 本章关键结论、常见误解、尚不确定或需要补充背景的内容。
8. 10–15道自测题及答案，包含概念、比较和机制推理题；将答案放在题目后单独的小节。
9. 术语表、关键知识之间的联系、可供下一轮追问的问题。

要求：
- 以本章教材为主要依据，明确区分“教材内容”“辅助解释”“推断/待核实”。不自动加入未经核实的前沿研究或虚构参考文献。
- 不逐字复刻长篇原文；用自己的话解释，不能以简单压缩摘要替代机制分析。
- 使用标准 Markdown 标题、列表、表格和 LaTeX。适合机制关系时可用短小 Mermaid 图，避免 HTML 和依赖插件的语法。
- 直接输出可粘贴到现有章节笔记“章节学习笔记”下的正文，从三级标题（###）开始，不添加 YAML，不重建文件夹，不声称已在我的本机保存文件。
- 涉及其他章节时可注明章号和标题；不要虚构 Obsidian 文件名。
- 若内容需要分多次输出，先说明分段计划，并在每段末注明覆盖到哪一小节、还有哪些未完成，不得用“已完整覆盖”掩盖截断。
- 最后附“覆盖核对表”：按原书小节列出已覆盖、图表是否核对、疑点与遗漏。

【Obsidian 笔记排版与视觉要求】

请将输出整理为一份适合长期学习、复习和维护的 Obsidian Markdown 笔记。整体风格应清晰、克制、有层次，接近高质量教材学习手册。保持内容完整，不能为了排版简洁而省略重要机制、条件和例外。

一、标题层级
1. 正文将粘贴到已有章节笔记的“## 章节学习笔记”下，因此从三级标题（###）开始，依次使用四级、五级标题，最多到五级，不跳级。
2. 原书主要小节使用三级标题；小节内的机制、细胞类型或功能模块使用四级标题；必要的细分主题使用五级标题。
3. 标题采用简洁、明确的中文，关键专业术语首次出现时附英文。
4. 标题之间应体现知识结构，避免将每个术语都拆成独立标题。

二、内容组织
1. 每个主要小节先用1–3句话说明“本节解决什么问题”和核心结论，再展开细节。
2. 机制解释以连贯短段落为主，每段集中说明一个问题；步骤、分类和并列关系使用列表。
3. 避免整页连续的长段落，也避免把完整解释拆成大量零碎短句。
4. 每个重要机制应说明：起始条件、作用主体、发生过程、生物学结果、调控与适用范围。明确区分因果关系、相关关系和推测。
5. 重要例外应紧跟相关结论，不要全部放到文末。

三、重点标记
请统一使用以下规则，使重点可以快速定位：
- **粗体**：关键术语、核心因果关系、重要区别；只突出最有信息量的词句，避免整段加粗。
- ==高亮==：必须掌握的核心结论，每个主要小节通常不超过1–2处；非必要时不使用。
- 普通正文：背景、展开解释和支持性细节。
- 不对同一句话重复叠加粗体、高亮和其他装饰。

重点应依据概念的重要性、机制的中心地位和易混程度确定。没有课程考纲时，不声称某内容“必考”。

四、使用 Obsidian Callout 突出不同信息
仅在确有必要时使用以下类型，不要每段都套提示框：

> [!abstract] 核心结论
> 用1–3句话概括本节最重要的机制或结论。

> [!info] 概念与背景
> 补充理解正文所需的定义或前置知识。

> [!tip] 理解线索
> 提供有助于理解或记忆的线索；若使用类比，说明类比的局限。

> [!warning] 易混点与适用边界
> 解释容易混淆的概念、重要例外、物种差异或结论的适用条件。

> [!question] 自测
> 提出需要解释机制、比较差异或进行推理的问题。

> [!note] 来源与待核实
> 标明辅助解释、推断或无法从当前教材核实的内容。

每个提示框只承担一种功能，保持简短。主体内容仍应放在正常正文中；不要嵌套提示框。自测答案可以使用可折叠格式：
> [!success]- 参考答案
> 答案与推理过程。

五、表格与机制图
1. 比较多个对象、整理受体与配体、归纳细胞因子来源与功能时使用表格。
2. 每张表围绕一个明确问题，通常控制在3–5列；单元格保持简洁，复杂机制在表格外解释。
3. 机制链条较短时使用文字箭头；存在分支、反馈或细胞间相互作用时，可使用 Mermaid。
4. Mermaid 使用标准语法，优先自上而下布局，标签简短；必要时拆成多个小图。
5. 图示之后解释关键步骤与限制，不能只给图而缺少机制说明。
6. 不使用 ASCII 图、HTML 排版、自定义 CSS 或依赖额外插件的语法。

六、统一视觉风格
1. 正常段落、列表、表格和提示框之间保留空行，保证直接粘贴后正确渲染。
2. 标题本身已能区分内容时，不额外添加分隔线。
3. 不在标题前密集添加 Emoji，不用装饰符号模拟标题层级。
4. 细胞、受体、基因、蛋白和细胞因子的命名应前后一致；专业名词不使用行内代码格式装饰。
5. 正文不放在代码围栏中；仅 Mermaid 图使用对应的代码围栏。
6. 同级内容采用一致的写法，避免不同小节的组织方式随意变化。

七、章节收束与质量检查
正文结尾设置：
- “本章知识主线”：串联本章重要机制。
- “核心结论速览”：提炼少量高价值结论。
- “易混概念对照”：集中比较关键区别。
- “自测与答案”：答案尽量折叠，方便主动回忆。
- “覆盖核对与待解决问题”：说明遗漏、疑点及无法核实的内容。

输出前检查：标题是否合理、重点是否突出但不过量、表格是否易读、提示框是否必要、机制解释是否完整，以及是否区分了教材内容与辅助解释。

## 第二轮：核对与补全

```text
请重新检查本章PDF与刚才的笔记。按原书小节逐项比对，检查遗漏、机制错误、术语混淆、物种差异、图表编号和页码。列出需要修改的条目，并提供可直接替换的 Markdown 段落。无法核对的项目明确标注，不能默认正确。不要仅重复原笔记。
```

## 粘贴与整理

保留章节笔记已有的文件属性、前后章导航、教材PDF链接和“本章原书结构”；将 Gemini 输出粘贴到“章节学习笔记”下。人工核对后更新 `status`。如 Gemini 输出含最外层 Markdown 代码围栏，粘贴时去掉最外层围栏。
