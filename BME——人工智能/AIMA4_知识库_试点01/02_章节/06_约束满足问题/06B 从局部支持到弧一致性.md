# 06B 从局部支持到弧一致性

**书页 156–159 · §6.2.1–6.2.4。** 传播从一个反问开始：如果 $X_i=x$ 真属于某个完整解，邻居 $X_j$ 能取什么值来支持它？找不到一个支持，就可以安全删去 $x$。

## 支持有方向

一元约束直接过滤域，例如 $SA\ne\text{绿}$。对二元关系 $R_{ij}$，弧 $i\to j$ 一致的条件为

$$
\forall x\in D_i,\quad\exists y\in D_j:\ (x,y)\in R_{ij}.
$$

把箭头读作“检查左端的每个值，在右端找支持”。以 $Y=X^2$、两个域都为 $\{0,\ldots,9\}$ 为例。检查 $X\to Y$ 后 $D_X=\{0,1,2,3\}$；检查 $Y\to X$ 时按相反方向解释同一关系，$D_Y=\{0,1,4,9\}$。若只检查第一条弧，$Y=8$ 仍在域里。

## AC-3 怎样找到不动点

教材图 6-3（书页 158）。队列中的 $(i,j)$ 表示 $D_i$ 可能含有在 $D_j$ 已失去支持的值。下面是按该不变量重写的伪代码。

```text
若有初始空域，报告不相容
队列 ← 每条边的两个方向
当队列非空：
    取出 (i,j)
    S ← D_i 中在 D_j 内没有支持的所有值
    若 S 非空：
        从 D_i 删去 S
        若 D_i 为空，报告不相容
        将所有 (k,i) 加回队列，其中 k 邻接 i 且 k ≠ j
返回剩余各域
```

**为什么跳过 $j$？** 本轮从 $D_i$ 删除的每个值与当前 $D_j$ 中的任何值都不配对，删除它们不会破坏 $D_j$ 中已有的支持。其他邻居可能恰好依靠被删值，必须重检。这一解释假设同一对变量的所有二元限制已经合并为同一关系。

**手算队列。** 取 $A<B<C$，域依次为 $\{1,2\},\{1,2,3\},\{2,3\}$。按下表选择出队次序，未列出的方向只做无变化检查。

| 检查 | 删除了什么 | 理由 |
|---|---|---|
| $B\to C$ | $B=3$ | 没有大于 3 的 $C$ |
| $B\to A$ | $B=1$ | 没有小于 1 的 $A$ |
| $A\to B$ | $A=2$ | $B$ 只剩 2 |
| $C\to B$ | $C=2$ | $B$ 只剩 2 |

最终解 $(1,2,3)$。**可靠性**来自归纳：任一完整解中对应的邻居值本身就是支持；先前保留全部解时，此次也保留全部解。**终止性**来自有限域的单调缩小。队列清空意味着每条弧都已检查过，或其支持域之后未发生相关变化。空域能证明当前分支无解；所有域非空仅证明达到了这一层局部一致性。

## 从逐边操作推出代价

令 $e$ 为无向二元边数，每次关系检验 $O(1)$，最大域为 $d$。一次修订最多为 $d$ 个候选各扫 $d$ 个支持，成本 $O(d^2)$。弧初始入队一次，之后仅在支持域变小时被再次触发；这样的事件最多 $d$ 次。有 $2e$ 条有向弧，所以

$$
T=O(2e(1+d)d^2)=O(ed^3).
$$

若队列去重，它最多同时含 $2e$ 条弧；域另占 $O(nd)$，关系表的存储另计。使用支持计数可得到不同的时间与内存权衡，见 [[06G 习题与研究任务]] 第 14 题。运行入口见 [[06D 回溯、启发式与约束学习]]。

**Python 小实验。** 以下从知识库的 code 目录启动 Python 后可直接运行。同一约束的两个方向必须交换参数；通过断言可以同时检查支持的方向和修订后的域。

```python
from csp import ac3

domains = {"X": set(range(10)), "Y": set(range(10))}
neighbors = {"X": ["Y"], "Y": ["X"]}

def square_relation(left, a, right, b):
    if left == "X":
        return b == a * a
    return a == b * b

assert ac3(domains, neighbors, square_relation)
assert domains == {"X": {0, 1, 2, 3}, "Y": {0, 1, 4, 9}}
```

## 两色三角形为什么逃过 AC-3

三条边均要求不同色。每个红色都有对面的蓝色支持，每个蓝色都有对面的红色支持，AC-3 不删任何值。检查两个端点取红、蓝能否**同时**延伸到第三点时，第三点被两种颜色都排除。路径一致性因此删除这个二元组；将两种次序都删除便得到空关系。路径一致性收紧的是二元关系，有时要为原先无边的变量对引入显式关系。

| 一致性 | 被检验的对象 | 需要的延拓 |
|---|---|---|
| 节点 | 单个候选 | 满足本变量的一元条件 |
| 弧 | 一个变量的值 | 在一个指定邻居中找到支持 |
| 路径 | 一对已兼容的值 | 在任一指定第三变量找到共同支持 |
| $k$ 一致 | 任意 $k-1$ 个变量的一致赋值 | 对任一指定的第 $k$ 个变量存在一致延拓 |
| 强 $k$ 一致 | 从 1 到 $k$ 的每一级 | 任意较短的一致前缀也能按相应层级延拓 |

**自行推导。** 对已知强 $n$ 一致的二元 CSP，任取顺序。第 $i$ 步试至多 $d$ 个候选，每个至多与 $i-1$ 个已赋变量检查，且至少一个成功。总检查数至多 $d\sum_{i=1}^n(i-1)=dn(n-1)/2$，故构造解为 $O(n^2d)$（含赋值开销）。建立这种强一致性本身可能需要指数时间和空间。比较仅需定向检查的树形特例，见 [[06F 图结构、割集与树宽]]。
