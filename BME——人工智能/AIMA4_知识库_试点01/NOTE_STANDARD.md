# NOTE_STANDARD

## 一页笔记如何让读者学会一个概念

开头提出可检验的问题，给出原书小节与中文书页。先展示一个足够小、可手算的例子，再定义符号、写出一般式、解释条件并说明反例。在结尾提供练习或与后续章节的联系。章节 MOC 只管导航；长推导有唯一主笔记。

| 内容类型 | 至少回答的问题 | 第 6 章样例 |
|---|---|---|
| 概念 | 对象、定义、反例、邻近术语为何易混？ | 两色三角形中的局部支持与整体可行性 |
| 公式与定理 | 前提、每步依据、量纲或计数对象、等号条件是什么？ | 一条弧的 $O(d^2)$ 修改怎样累积成 $O(ed^3)$ |
| 算法 | 输入输出、不变量、停止条件、执行痕迹、时间与内存依赖什么？ | AC-3 入队方向；有空域与队列清空的不同结论 |
| 图与表 | 轴、节点、边、颜色或单元格表示什么；读者能据图推出什么？ | 将着色图的色块还原成候选表，并手算 |
| 例题与习题 | 来源、难度、题设、步骤、答案核验，有无多个解？ | 6.NARY 双向证明；随机实验报告预算、种子和失败 |
| 拓展 | 与教材的关系、证据来源与边界是什么？ | 独立推导 $w\le c+1$；近似割集的文献入口 |

## 文件和来源约定

- UTF-8 Markdown。章目录名为两位章号加中文名。MOC 用 MOC-NN 加章名；知识页用两位章号、稳定字母与标题。重命名时同步修复全库入链。
- 每篇有 YAML 字段 id、title、type、status、tags。直接基于章节的笔记另有 chapter、source_file、source_pages。目录和项目页的来源在正文写明。标签统一从 aima4 与文种开始。
- 来自书上具体定义、图或例子的段落写原书页码；同一笔记跨多个原页时在段落内再标定位。自行计算写“自行推导／推演”或“本库实验”；外部资料附作者、题名或站点和可访问链接。独立编写的解释不作为教材原句。
- 若抽取结果和可视原页冲突，按原页校订。若原书数学结论有疑义，同时保留原书表述、可检验反例及独立推导。未能核实的事实或解题步骤记“待核实”并登记审核清单。
- 习题分成“教材正文例题”“配套在线题”“自拟练习”。配套题给题号或稳定标识，按主题、难度归类；实测结果不能代替一般性证明。

## 排版与可移植性

行内式使用单美元符，独立式使用双美元符。含绝对值、条件竖线或集合基数的表格公式优先使用 LaTeX 命令，避免竖线切断 Markdown 表格。场景分支、依赖关系使用 Mermaid；需要位置精确的数学图放进 assets/chNN，用相对路径嵌入。颜色必须有文字或形状对应。代码块标语言，伪代码用 text，命令用 shell。附可运行文件时给出从知识库根目录执行的命令。

```yaml
---
id: ch06-b
title: "06B 从局部支持到弧一致性"
type: 知识点
status: 试点已编写
tags: [aima4, 知识点]
chapter: 6
source_file: "06_第6章 约束满足问题.pdf"
source_pages: "156–159"
---
```

重要提醒使用 Obsidian 的 note、example、question 或 important callout。公式、代码、图形各保留可读的文字解释。内链使用不重复的文件标题；目标尚无笔记时，先链 [[原书目录]] 的真实章标题。原书 PDF 保存在原路径，笔记引用始终同时保留可人工查找的书页。

## 审核与状态

每章核对小节覆盖、数学、算法、代码、图表、习题、来源、链接、重复、可读性十项。记录证据、具体缺口和修订结果；结构扫描通过不等于命题正确。试点后可据读者反馈调整篇幅与图表密度，规范版本与状态同步到 [[PROGRESS]]。
